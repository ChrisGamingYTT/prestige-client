## 5-Minute GitHub Build Process

### Step 1: Create Free GitHub Account (2 min)
- Go to https://github.com/signup
- Fill in details
- Verify email
- Done!

### Step 2: Push Your Code (2 min)

Open PowerShell in your project folder:
```bash
cd "d:\AI APPS\CLAclient"

git init
git add .
git commit -m "Prestige Client v1.0.0"
git remote add origin https://github.com/YOURNAME/prestige-client.git
git branch -M main
git push -u origin main
```

### Step 3: Wait for Build (1 min)
- Go to your GitHub repository
- Click "Actions" tab
- Wait for green checkmark
- Build completes in 2-3 minutes

### Step 4: Download JAR (instant)
- Go to the completed build
- Click "prestige-client-jar"
- Download the ZIP
- Extract to get: `prestige-client-1.0.0.jar`
